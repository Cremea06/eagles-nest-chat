# afirstflag.com

Public site for America First Flags — numbered yard flags and the Eagles Nest community.

Live: https://afirstflag.com  
Chat (separate repo): https://github.com/Cremea06/eagles-nest-chat  
Live chat: https://chat.afirstflag.com

Buy flow is a Stripe Payment Link from the red window on the homepage.  
This repo is static HTML/CSS/JS (Namecheap / Apache).
